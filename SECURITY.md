# Security Policy

## Supported versions

Only the latest commit on `master` is supported.

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/luzyver/QRISGuard/security/advisories/new).

Include the affected component, reproduction steps, and potential impact. Do
not include real payment notifications, QRIS payloads, passwords, or tokens.

Until a fix is available, keep the webhook and PostgreSQL service on a private
network and rotate any credential that may have been exposed.
